# Источники мем-шаблонов

Финальные PNG собраны локально из публичных шаблонов Imgflip и дополнены
русскими подписями. AI-генерация в итоговых файлах не используется.

| Триггер | Шаблон | Источник |
|---|---|---|
| `peace` | Guy disappearing peace sign | https://imgflip.com/memetemplate/245914785/guy-disappearing-peace-sign |
| `one_finger` | One Does Not Simply | https://imgflip.com/memetemplate/61579/One-Does-Not-Simply |
| `open_palm` | Stop it. Get some help | https://imgflip.com/memetemplate/77155067/stop-it-Get-some-help |
| `mouth_open` | Surprised Pikachu | https://imgflip.com/memetemplate/163214423/Suprised-Pikachu |
| `tongue_out` | Cat tongue | https://imgflip.com/memetemplate/310161921/Cat-tongue |

Сборка повторяется командой:

```bash
.venv/bin/python scripts/build_internet_memes.py
```
